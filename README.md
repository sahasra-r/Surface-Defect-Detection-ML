# 🧠 Machine Learning Detection of Industrial Surface Defects

This project focuses on detecting industrial surface defects using machine learning techniques applied to multi-domain inspection images. The system automates defect classification, improving accuracy and reducing manual inspection effort.

---

## 📌 Features

- 📂 Dataset loading from folder structure
- 🧹 Image preprocessing and feature extraction
- 📊 Exploratory Data Analysis (EDA)
- 🤖 Multiple Machine Learning algorithms
- 📈 Performance evaluation (Accuracy, Precision, Recall, F1-score)
- 🖥️ GUI-based application using Tkinter
- 🔍 Image-based defect prediction
